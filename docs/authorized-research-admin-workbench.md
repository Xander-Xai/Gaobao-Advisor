# Authorized research operator workbench

Separate from the synthetic admin experiment. On the Agent research tab an operator can submit an approved cohort, inspect a run, cancel it or view the private verified report. A different administrator reviews the immutable scope, model, image and external authorization record before approval. No browser execution action, no paid call, no automatic replay and no personal profile inputs. Stable idempotency for retry of the same form within one mounted session. Backend PR #184 provides the authenticated routes; if absent or disabled the workbench reports an explicit unavailable state. Run IDs are supplied by the submitter; list/search and public chat integration are not part of this change. Frontend tests use mocked HTTP results; full business E2E and actual provider acceptance still required.
