# Private admissions research report

An optional `--report-out /private/research.txt` on the existing authorized
`python -m server.agent.admissions_deepagents` operator command produces a
readable report from the verified in-process evidence, not model prose.
The JSON receipt remains the source. New files only, mode 0600 on POSIX.
Blocked research produces no report. Partial coverage is explicit.
The renderer verifies evidence and sandbox hashes and preserves the
enrollment-plan subject requirement without claiming cohort eligibility:
the plan table does not have a subject_type column.

Validation: `pytest -q tests/test_admissions_deepagents.py`.
No external model execution, real data approval, public route, persistent
TaskRun, source authenticity or admission prediction is claimed.
