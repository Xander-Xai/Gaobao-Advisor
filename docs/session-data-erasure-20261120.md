P28: Authenticated DELETE /api/v1/profile/{session_id}/data purges live conversation profile/slots, messages, feedback, highlights, quality scores and locally stored JSON reports. Report files are moved to inaccessible staging first, restored on SQL rollback, then physically deleted after DB commit; symlink/unrecognized files fail closed. This does NOT purge DB backups, WAL forensic remnants, external processor data, nor prevent re-creation of the same session by a later request. Concurrency and recovery require operator policy; HTTP returns 503 for incomplete cleanup, never claims global GDPR erasure. Tests: tests/test_session_data_erasure.py.
