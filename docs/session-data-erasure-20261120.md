This does NOT purge DB backups, WAL forensic remnants, external processor data, nor prevent re-creation of the same session by a later request. Concurrency and recovery require operator policy; HTTP returns 503 for incomplete cleanup, never claims global GDPR erasure. Tests: tests/test_session_data_erasure.py.
